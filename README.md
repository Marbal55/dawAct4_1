# Actividad 1.4 - Uso avanzado de GitHub

## Descripción del proyecto

Este repositorio pertenece a la actividad 1.4 de la asignatura de **Desarrollo de Aplicaciones Web (DAW)**.

El objetivo es aprender a utilizar herramientas avanzadas de GitHub, como Markdown y GitHub Pages, para documentar y publicar proyectos web.

### Contenido del proyecto

En este repositorio podemos encontrar una página web que muestra algunos de los módulos que se estudian en el ciclo de DAW.

Los módulos incluidos son:

- Desarrollo de interfaces.
- Despliegue de Aplicaciones Web.
- Python.
- Servidor y cliente.
- Java.
- Bases de datos.

**Tecnologías utilizadas:** HTML, CSS, JavaScript y Markdown.

*Este proyecto tiene una finalidad educativa.*
